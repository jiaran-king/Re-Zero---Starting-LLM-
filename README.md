# LLM-start

这是一个面向长期学习和复盘的 Obsidian LLM-WIKI，主要整理大语言模型相关知识、论文资料、工程框架和实验经验。

仓库的目标是把资料逐步整理成可复用的知识网络：

```text
原始资料
  -> 资料索引
  -> 概念笔记
  -> 主题地图
  -> 项目 / 实验沉淀
```

## 如何阅读

如果你是第一次打开这个仓库，建议按下面顺序：

1. 先看 [LLM 全流程总览](01-主题地图/0a.LLM全流程总览.md)，建立整体框架。
2. 再看 [LLM 学习地图](01-主题地图/0.LLM学习地图.md)，选择具体主题。
3. 进入对应主题页，例如 [基础架构](01-主题地图/基础架构.md) 或 [后训练与对齐](01-主题地图/后训练与对齐.md)。
4. 从主题页进入 `02-概念笔记` 中的具体概念页。
5. 需要追溯来源时，再回到 [资料索引](05-资料摘录/资料索引.md) 和 `05-资料摘录`。

## Obsidian 使用说明

这个仓库按 Obsidian vault 组织。直接用 Obsidian 打开仓库根目录即可。

需要注意：

- Obsidian 的 `[[双链]]` 在 GitHub 上不会像 Obsidian 内部一样完整解析。
- README 中的主要入口使用标准 Markdown 链接，适合 GitHub 浏览。
- `.obsidian` 中只保留必要配置；本地缓存、插件、主题、工作区状态等已通过 `.gitignore` 排除。
- `08-图片` 中的 Canvas 文件可在 Obsidian 中查看，GitHub 只能显示 JSON 文本。

## 资料与版权边界

本仓库用于个人学习、整理和知识索引。

- 论文、技术报告、项目页面等外部资料尽量登记官方链接。
- PDF 原文默认不作为公开分发对象，已在 `.gitignore` 中排除 `*.pdf`。
- 资料摘录和读书笔记只作为学习整理，不替代原文。
- 如果要引用具体结论，应优先回到原论文、官方文档或项目页面核对。

## 维护原则

本仓库的整理规则写在 [AGENTS.md](AGENTS.md) 和 `00-首页与索引` 中。核心原则是：

- 总图只做导航，不直接连接大量具体概念。
- 主题页承接概念页，概念页沉淀可复用知识。
- 原始资料留在 `05-资料摘录` 或 `07-待整理`，不要直接混入主题图谱。
- 项目记录和实验日志保留过程语境，不强行改成概念页。
- 批量整理后同步更新主页、索引、资料索引和处理日志。

## GitHub 同步前检查

同步到 GitHub 前建议检查：

```bash
git status --short
git add .
git status --short
```

重点确认不要提交：

- 本地工作区状态：`.obsidian/workspace.json`
- 插件、主题和缓存：`.obsidian/plugins/`、`.obsidian/themes/`、`.obsidian/cache/`
- PDF 原文：`*.pdf`
- 实验输出、checkpoint、日志：`outputs/`、`checkpoints/`、`wandb/`、`*.log`
- 私钥、证书、环境变量：`.env`、`*.pem`、`*.key`
