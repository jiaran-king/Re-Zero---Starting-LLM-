## 2. 主主题域

```text
基础架构
  -> 预训练
  -> 后训练与对齐
  -> 参数高效微调
  -> 推理优化

训练系统工程横切以上所有阶段。
```

| 主题 | 一句话定位 |
|---|---|
| [[基础架构]] | 模型如何表示输入，Transformer 如何组织计算 |
| [[预训练]] | 基座模型能力如何从数据、目标函数和计算预算中形成 |
| [[参数高效微调]] | 如何少更新参数也能适配任务 |
| [[后训练与对齐]] | 模型如何从续写器变成可用助手，并进一步提升推理能力 |
| [[推理优化]] | 模型训练完后如何更快、更省、更稳地服务请求 |
| [[训练系统工程]] | 训练、后训练和推理在工程上如何跑得动、可恢复、可观察 |

## 3. 主题页使用规则

- 总图不挂具体概念，具体概念进入各主题页。
- 综合资料、论文阅读、框架学习笔记放在主题页的“重点资料”区，不当作基础概念节点。
- 如果一个方向只有 1-3 篇笔记，先作为主题页中的小节，不单独拆主题页。
- 当一个主题稳定超过 5-8 篇正式概念页，再考虑拆新主题页。
