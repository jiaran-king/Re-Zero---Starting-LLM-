# 后训练与对齐

> [!note]
> 本页承接预训练之后的行为塑形：SFT、偏好优化、RLHF、DPO、PPO、GRPO、Rollout、自我进化和 Reasoning RL。

## 1. 主干路径

```text
Pretrain
  -> SFT
  -> Preference Data / Reward Model
  -> Offline Preference Optimization 或 Online RL
  -> Reasoning RL / Self-improvement
```

## 2. 概念地图

| 模块 | 作用 | 当前入口 |
|---|---|---|
| 监督后训练 | 学指令格式、任务接口、基础助手行为 | 待补：SFT |
| 偏好建模 | 把人类偏好或规则判断变成优化信号 | 待补：Reward Model、Preference Data |
| 经典 RLHF | SFT + RM + PPO 的完整框架 | [[RLHF]] |
| 在线 RL | 采样 response，再用 reward / advantage 更新策略 | [[Rollout]]、[[PPO]]、[[GRPO]] |
| 离线偏好优化 | 不显式训练 RM + PPO，直接用偏好对优化 | [[DPO]] |
| 自我进化 | 采样、验证、过滤、再训练 | [[Expert Iteration]] |
| RL 基础量 | reward、return、value、advantage、GAE、policy gradient | [[LLM_后训练 Reward Return Value Advantage]] |
| Reasoning RL | long-CoT、可验证奖励、DAPO recipe、overlong reward shaping | [[DAPO：大规模长链推理强化学习系统]] |
