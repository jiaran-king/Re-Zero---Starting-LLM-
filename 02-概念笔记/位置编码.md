# 位置编码

> [!note]
> Transformer 中为 token 序列注入位置信息的机制。因为 self-attention 本身是排列不变的（permutation invariant），模型无法从纯内容 embedding 中区分"第 1 个词"和"第 10 个词"，必须通过额外手段注入顺序信号。主流方案分为绝对位置编码和相对位置编码两大类，其中 **RoPE 是当前 LLM 最核心的方案**（LLaMA、Qwen、DeepSeek 等均采用）。

---

## 一、绝对位置编码

### 1.1 可学习位置编码（Learned PE）

给第 $0, 1, 2, \ldots$ 个位置各分配一个可训练向量，加到 token embedding 上。做法和词向量类似，模型自己学每个位置的表示。

优点是简单直接；缺点是对超出训练长度的序列泛化较差——模型没见过的位置编号没有对应的嵌入向量。

### 1.2 正弦余弦位置编码（Sinusoidal PE）

原始 Transformer 论文（Vaswani et al., 2017）提出的方法。用不同频率的 sin/cos 函数构造每个位置的向量：

$$PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d}), \quad PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d})$$

不需要学习参数，且对更长序列有一定外推能力（因为三角函数的周期性提供了某种连续性）；但灵活性不如可学习方法。

---

## 二、相对位置编码

相对位置编码不再强调"当前位置是第几位"，而是强调"两个 token 相距多远"。这更符合注意力的本质——注意力本来就在比较 token 两两之间的关系。

### 2.1 Relative Position Bias

直接给 attention logits 加一个与相对距离有关的偏置项。距离越近偏置越大，距离越远偏置越小或为零。T5 等模型中很常见。

实现简单，适合长序列；但表达能力有限，偏置项通常是查表或分桶得到。

### 2.2 ALiBi（Attention with Linear Biases）

在 attention 分数上加一个与相对距离成**线性关系**的 bias：

$$b_{ij} = -\alpha \cdot |i - j|$$

参数少、实现轻量、长文本外推能力不错；但表达能力通常不如 RoPE 细腻。

### 2.3 RoPE（Rotary Position Embedding）

当前最主流的位置编码方案。它不是把位置向量加到 embedding 上，而是把 Query 和 Key 的每一对维度做**旋转**，让位置关系自然体现在点积里。

对第 $i$ 个频率通道，RoPE 的角频率为 $\omega_i = b^{-2i/d}$，位置 $p$ 的旋转角为：

$$\theta_i(p) = p \cdot \omega_i = p \cdot b^{-2i/d}$$

其中 $b$ 是 base（常见默认值 $10^4$），$d$ 是 head 维度。不同维度用不同频率随位置旋转，相位差进入 $q,k$ 内积后就把相对位置信息编码进了 attention score。

**为什么 RoPE 主流？** 它能很好地表达相对位置信息，并且和注意力机制结合得自然——改的是 Q/K 本身而非 attention logits，因此与各种 attention 变体（MHA/GQA/MLA 等）兼容性好。

---

## 三、RoPE 的长上下文扩展

标准 RoPE 在训练长度内效果很好，但如果直接把上下文硬拉到超出训练范围，会出现高频分量变化过快、位置相位分布失真、远距离 attention 衰减等问题。以下方法用于缓解这些问题：

### 3.1 YaRN（Yet another RoPE extensioN）

**改进位置编码缩放**。核心思路是不粗暴地统一压缩所有位置，而是更平滑地重映射 RoPE 的位置尺度：

$$p \mapsto g(p)$$

即把原始位置 $p$ 通过一个温和的映射函数变成新位置，再送入 RoPE。近距离部分尽量少动保住原有能力，远距离部分逐渐压缩让超长位置落进可处理范围。

可以理解为一种"分段、稳定"的 RoPE scaling——比简单线性缩放更不容易出现性能崩塌。

### 3.2 DCA（推理期注意力修正）

**解决的问题是**：即使训练时做了长上下文扩展，推理阶段随着上下文继续拉长，RoPE 仍可能导致 attention 分数系统性失真——越远的位置越不易被正确关注，模型偏向近邻 token。

DCA 在推理时修正这种现象，本质上是**把"绝对位置直接做差"的相对位置矩阵替换成"按块分段重编号后再做差"的矩阵**。效果有两个：
- 超长上下文下相对位置不再越界，避免未见过的超大距离上失真
- 相邻块之间加了 successive-chunk 修正，不完全牺牲局部连续性

### 3.3 ABF（Adaptive Base Frequency）

不改 RoPE 基本形式，只改 **base $b$**，让旋转角增长得更慢：

$$\theta_i(p) = p \cdot b^{-2i/d}, \quad b \gg 10000$$

例如 Qwen2.5 将 base 从 $10^4$ 提高到 $10^6$，后续更长阶段继续提高到 $10^7$。数学效果：

$$b \uparrow \Rightarrow \omega_i \downarrow \Rightarrow \theta_i(p) \text{ 增长更慢}$$

高频旋转变慢、远距离衰减减轻、上下文可外推到更长范围。"Adaptive" 指的是为某个长上下文阶段选更大的 base，不是每个 token 实时自适应。

### 3.4 四者的定位对比

| 方法 | 改的是什么 | 层面 |
|------|-----------|------|
| YaRN | 位置映射 $p \mapsto g(p)$ | 训练 + 推理 |
| DCA | 推理时的注意力分数修正 | 仅推理 |
| ABF | 频率 $\omega_i = b^{-2i/d}$ 中的 base $b$ | 训练 |

三者常配合使用。**长上下文能力 = 训练期长度扩展 + 推理期位置/注意力外推修正**，不是单靠训练堆出来的。

## 四、其他变体

- **xPos**：在 RoPE 基础上引入指数衰减的位置权重，改善长程衰减特性
- **LongRoPE**：通过大幅扩大 RoPE 的 base 并重新初始化位置嵌入来实现超长上下文
- **二维位置编码**：Vision Transformer 中使用，同时编码行和列位置（图像是二维网格）

---

## 五、学习优先级

如果从大语言模型角度学习，推荐路径：

$$\text{sin/cos} \to \text{learned PE} \to \text{relative bias} \to \mathbf{RoPE} \to \text{ALiBi} \to \text{YaRN / DCA / ABF}$$

一个值得记住的关键区分：**RoPE 改的是 Q/K 本身，Relative Bias / ALiBi 改的是 attention logits**。

> [!warning]
> - 位置编码的选择会影响模型的外推能力，但不影响短序列内的表现——同一模型换不同的位置编码方案，在训练长度内效果差异通常不大
> - YaRN / DCA / ABF 不是新的主体架构，而是"让 RoPE 模型在比训练时更长的序列上仍然可用"的技术，属于 RoPE 生态的扩展
> - 二维位置编码只在 Vision Transformer 等非序列场景中使用，NLP 任务中不涉及
