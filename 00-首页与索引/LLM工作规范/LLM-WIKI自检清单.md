# LLM-WIKI 自检清单

## 1. 触发时机

每完成一个主题、批量整理一次资料，或新增 5 篇正式笔记后，执行一次自检。

## 2. 单篇概念页检查

- [ ] 是否有清晰定义？
- [ ] 是否说明为什么重要？
- [ ] 是否说明核心机制？
- [ ] 是否有上位主题？
- [ ] 是否有至少 2 个横向相关概念？
- [ ] 是否标注来源资料？
- [ ] 是否有待补充或待验证问题？
- [ ] 是否已经挂入对应主题地图？

## 3. 主题地图检查

- [ ] 是否有主题定位？
- [ ] 是否列出核心问题？
- [ ] 是否有概念地图，而不是只有零散链接？
- [ ] 是否标注重点资料？
- [ ] 是否标注项目关联？
- [ ] 是否有待补问题？
- [ ] 是否避免和总图重复直连同一批概念？
- [ ] 总图是否只连接总览页和主主题域，而没有重新直连大量具体概念？
- [ ] 主主题域与 [训练系统工程](../../01-%E4%B8%BB%E9%A2%98%E5%9C%B0%E5%9B%BE/%E8%AE%AD%E7%BB%83%E7%B3%BB%E7%BB%9F%E5%B7%A5%E7%A8%8B.md) 的边界是否清楚，避免横切工程层替代具体主题归属？

## 4. 资料层检查

- [ ] `05-资料摘录` 中的新资料是否登记到 [资料索引](../../05-%E8%B5%84%E6%96%99%E6%91%98%E5%BD%95/%E8%B5%84%E6%96%99%E7%B4%A2%E5%BC%95.md)？
- [ ] 资料状态是否是 `raw` / `summarized` / `extracted` / `integrated` / `archived` 之一？
- [ ] 已摘要资料是否提取了可拆概念？
- [ ] 已抽概念资料是否更新到概念页？
- [ ] PDF 是否保留为 source，而不是直接当作主题地图节点？

## 5. 项目和日志检查

- [ ] 项目页是否保留项目语境，而不是强行变成概念页？
- [ ] 实验日志是否保留过程、决策和结果？
- [ ] 是否有反复出现的项目经验值得抽象到 `02-概念笔记`？
- [ ] 项目页是否链接到实际用到的概念页？

## 6. Inbox 检查

- [ ] `07-待整理` 文件是否超过 10 篇？
- [ ] 每篇待整理材料是否能判断去向？
- [ ] 论文摘录是否应转入 `05-资料摘录`？
- [ ] 可复用概念是否应转入 `02-概念笔记`？
- [ ] 项目方案是否应转入 `03-项目笔记`？
- [ ] 实验过程是否应转入 `04-实验与日志`？

## 7. 全局一致性检查

- [ ] 是否有重复概念页或同义页面？
- [ ] 是否有孤立概念页？
- [ ] 是否有同一概念同时被总图和主题页重复承接？
- [ ] 是否有过期结论没有标注？
- [ ] 是否有待验证结论被写成确定事实？
- [ ] [index](index.md) 是否反映了新增关键页面？
- [ ] [主页](../%E4%B8%BB%E9%A1%B5.md) 和 [index](index.md) 是否同步反映了主题地图的新增、删除、合并或重命名？
- [ ] [LLM-WIKI处理日志](LLM-WIKI%E5%A4%84%E7%90%86%E6%97%A5%E5%BF%97.md) 是否记录了批量整理动作？
